## 1.0.0-beta.4

* Add `swoopmist export --snapshot <output.json>`, which writes SwoopKit's `ReleaseDataSnapshot`: the release-data file Stewed bundles as `Resources/release-data-snapshot.json`, replacing Stewed's `StewedTools` (brightdigit/Stewed#194). It reads only `SDKVersion`, `XcodeVersion` and `SimulatorRuntime`, maps every record with `from(recordInfo:)`, and fails on an empty type or any record that doesn't map, naming the records that didn't. Records are sorted by record name, `fetchedAt` is whole seconds, and the JSON is SwoopKit's `JSONEncoder.iso8601PrettySorted` plus a trailing newline, byte-identical to StewedTools' output for the same data. It only reads by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/46
* `export --snapshot` uses Development by default. Production needs `--allow-production`, a command-line flag only: no `SWOOP_*` variable turns it on. `--output`, `--pretty`, `--signed-only` and `--no-betas` are refused alongside `--snapshot` rather than ignored by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/46
* Add `ReleaseDataSnapshotExport` and `SyncEngine.exportSnapshot(fetchedAt:)` to the library, so the snapshot can be built and tested without the CLI or CloudKit by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/46
* Close the 200-record cap (#17): `export` and `export --snapshot` read every record through MistKit 1.0.0-beta.6's paging `queryAllRecords`, with a regression test that keeps 450 records of one type by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/46
* CI: the sync action's summaries now count SDK versions and simulator runtimes, and the sync summary lists the `SDKVersion` records it deleted. The stale "limited to 200 records per type" notes are removed by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/47
* Dependencies: SwoopKit `from: "1.0.0-beta.2"` (was `1.0.0-beta.1`), which now provides `ReleaseDataSnapshot` and its JSON coders. MistKit and the other dependencies are unchanged

**Full Changelog**: https://github.com/brightdigit/SwoopMistKit/compare/1.0.0-alpha.3...1.0.0-beta.4

## 1.0.0-alpha.3

* **Breaking:** BushelCloud is now SwoopMistKit: the package, the repository ([brightdigit/SwoopMistKit](https://github.com/brightdigit/SwoopMistKit); the old URL redirects), the library product `BushelCloudKit` → `SwoopMistKit` and the executable `bushel-cloud` → `swoopmist` (target `SwoopMistKitCLI`). Depend on `.product(name: "SwoopMistKit", package: "SwoopMistKit")` and `import SwoopMistKit` by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* **Breaking:** `BushelCloudKitService` is `SwoopMistKitService` and `BushelCloudKitError` is `SwoopMistKitError`; rename call sites. `BushelConfiguration` and `ValidatedBushelConfiguration` are now `SwoopMistKitConfiguration` and `ValidatedSwoopMistKitConfiguration`, with deprecated typealiases under the old names by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* **Breaking:** The record types (`RestoreImageRecord`, `XcodeVersionRecord`, `SwiftVersionRecord`, `DataSourceMetadata`, and the new `SDKVersionRecord` and `SimulatorRuntimeRecord`) come from [SwoopKit](https://github.com/brightdigit/SwoopKit) instead of BushelKit, and the BushelKit dependency is gone; SwoopMistKit owns its logging and fetch helpers. Add SwoopKit and `import SwoopKit` wherever you used the BushelKit record types by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* **Breaking:** The default container is `iCloud.com.brightdigit.Swoop` (was `iCloud.com.brightdigit.Bushel`). Set `CLOUDKIT_CONTAINER_ID` to keep writing to the old one, and import `schema.ckdb` into the new one with `Scripts/setup-cloudkit-schema.sh` by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* **Breaking:** Requires Swift 6.4 (swift-tools-version 6.4, was 6.2) in Swift 6 language mode, with `ExistentialAny` and `InternalImportsByDefault` (#36) by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/37
* Environment variables use the `SWOOP_` prefix (`SWOOP_SYNC_DRY_RUN`, `SWOOP_FETCH_INTERVAL_GLOBAL`, …). The `BUSHEL_*` names still work, with a deprecation warning, and a `SWOOP_*` value wins when both are set. `CLOUDKIT_*` and `VIRTUALBUDDY_API_KEY` are unchanged by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Fix the documented `swoopmist` flags, which were ignored in 1.0.0-alpha.2 too: `sync --dry-run` wrote to CloudKit, and `--verbose`, `--no-betas`, `--force`, the `--*-only` filters, `export --output`/`--pretty`/`--signed-only` and the `--cloudkit-*` options had no effect (the flags were read as `--sync-dry_run` and so on; only `delete-runtimes --confirm-delete` worked). Every key now names its flag, and a flag is read only from the command line and a variable only from the environment. These now work as flags too: `sync --runtimes-only`, `--no-apple-wiki`, `--min-interval`, `--source`, `--json-output-file`; `list --restore-images`/`--xcode-versions`/`--swift-versions`; `status --errors-only`/`--detailed`; `clear --yes`; `--cloudkit-container-id`, `--cloudkit-environment`, `--virtualbuddy-api-key`, `--fetch-interval-global` and `--fetch-interval-<source>`. The `SWOOP_*` and `BUSHEL_*` variables are unchanged by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Add `SDKVersion` records: `SDKVersionBuilder` derives platform SDK builds from xcodereleases.com and Apple's simulator index (Apple's wins; release days are UTC), links each to its `XcodeVersion`, and points a beta SDK's `supersededBy` at the final SDK by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Add `SimulatorRuntime` records from Apple's `index2.dvtdownloadableindex` (`SimulatorIndexFetcher`, `SimulatorRuntimeBuilder`), with `releaseLabel` parsed from the runtime name and the SDK builds stored as the comma-separated `sdkBuildNumbersText` (MistKit can't decode `STRING_LIST` yet). `sync --runtimes-only` (or `SWOOP_SYNC_RUNTIMES_ONLY=true`) syncs only runtimes by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Add the `delete-runtimes` command, which deletes only `SimulatorRuntime` records, in Development only, and is a dry run unless `--confirm-delete` by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* `schema.ckdb` adds `SDKVersion` and `SimulatorRuntime`; `SDKVersion`, `XcodeVersion` and `SimulatorRuntime` grant `READ, CREATE, WRITE` to `_creator` and `READ, CREATE` to `_icloud` by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Uploads run in reference order (SwiftVersion and RestoreImage, then XcodeVersion, then SDKVersion with finals before prereleases, then SimulatorRuntime), so a referenced record always exists first by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Update to MistKit 1.0.0-beta.4 and its `FieldValue` arity (`.string(.value(x))`) (#35) by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/37
* CI: Swift 6.4 release images on Ubuntu noble (plus jammy for PRs into `main`), Apple lanes on the `xcode-27` runner with Xcode 27.2 (macOS and iOS; watchOS, tvOS and visionOS for PRs into `main`), a DocC job, lint on `ubuntu-24.04`, workflows on `pull_request` only, `dependency-policy.yml` (no branch dependencies into `main`) and `check-unsafe-flags.yml` by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Tooling: swift-format 604 and SwiftLint 0.65 pinned in `mise.toml`, `Scripts/lint.sh`, `Scripts/docc.sh` and a Makefile; the DocC catalog is now `SwoopMistKit.docc`; `AGENTS.md` and `.agents` for contributors and coding agents by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Tests: a `Platform` helper (`Tests/SwoopMistKitTests/Helpers/Platform.swift`) with `Platform.isMacOSOrLinux`; the VirtualBuddy fetcher suite uses `.enabled(if: Platform.isMacOSOrLinux)` instead of an inline `#if` closure
* Documentation: the README and DocC articles are rewritten for SwoopMistKit, and the Bushel-era content is removed by @leogdion in https://github.com/brightdigit/SwoopMistKit/pull/44
* Dependencies: SwoopKit `from: "1.0.0-beta.1"` and MistKit `from: "1.0.0-beta.6"`; adds FelinePine and FelinePineSwift (Linux, Android, OpenBSD, WASI and Windows only); removes BushelKit. ConfigKeyKit, IPSWDownloads, SwiftSoup and swift-configuration are unchanged
